八科怎麼學
自學互動手冊

這一年最重要的不是考幾分，是找到自己的方法：知道怎麼讀、遇到不懂時知道怎麼辦。

記住理解應用與表達
八科內容不同，路是同一條。

先看一眼全貌

點一科進去，裡面有這科在學什麼、老師怎麼上、你可以怎麼做，還有一張自我檢核表。

這本手冊怎麼用：用輸出檢查輸入

讀過不等於讀懂。要檢查有沒有真的讀進去，方法只有一個——闔上課本，把它說出來或寫下來。講得零零落落的地方，就是還沒讀懂的地方。
  1. 先輸入：讀一遍，或按每一科的語音導覽聽一遍。
  2. 再輸出：闔上，用自己的話說一次、寫三句。
  3. 後對照：這時才打開重點，看自己漏掉什麼——那就是今天要補的。

每一科頁面下方都有「換你說」的輸出練習；「今天」分頁會帶你把這三步走完一輪。

不管哪一科，都適用的五件事

  1. 考完先問自己「哪裡還不懂」，而不是只看分數。
  2. 學完的東西，試著用自己的話說一次。說得清楚，才是真的懂。
  3. 訂正不是把答案改對，是找出錯的原因。
  4. 把課本裡的東西，在生活中找到一次。
  5. 國七先建立方法，成果會慢慢累積。
從「記住」到「理解」，再走向「應用與表達」。
這句話八科老師都寫了一遍——不是巧合，是同一個目標。

國文

閱讀 × 理解 × 表達

國文是日積月累的科目。眼睛閱讀、頭腦分析、文字練習——基本功夠了，考場上才發揮得出來。

基本功怎麼練

  • 每一課都要熟讀：形、音、義、作者、課文賞析。
  • 多做題目，並且從題目中反過來彙整每課重點。
  • 課外多讀時事、散文、科普類文章，讀完寫 100～200 字心得。

三種閱讀題型

古典散文（文言文）·韻文（詩、詞、曲、新詩）·白話散文與新詩

文言文：三個解題重點

  1. 哪些字詞可以用白話文替換。
  2. 虛字怎麼判斷。
  3. 比較古今差異，分析人、事、時、地、物、心理變化與哲思啟發。

韻文：三種考法

  1. 依格律找出排列方式：押韻、對仗、平仄。
  2. 看出背後的深意，或作者借景抒情、借物言志的手法。
  3. 找出詩眼（關鍵字詞），就掌握了古詩理解的要領。

現代散文與新詩：三個步驟

  1. 不管文章多長，先看清楚題目問什麼方向。
  2. 找出關鍵句或段落，逐條劃線，判斷主詞與主旨。
  3. 把答案放回題幹驗證一次，看是否符合文意。

新詩的意象常常就藏在題目裡，而且多半和生活經驗有關——平常多注意身邊的人事物。

考題會取材自題辭、寒暄用語、徵人啟事這類應用文，也會用名人軼事、報章雜誌、媒體廣告、科普文章。課本以外的閱讀，不是額外，是範圍。

英文

單字 × 文法 × 閱讀

會考題型不外乎單字、文法、閱讀理解。回家作業只要確實認真寫，英文不難拿高分。

課會這樣上

  1. 上課分成四塊：單字、文法、課文、對話。
  2. 上完單字、課文、對話 → 單字、課文及對話克漏字小考。
  3. 上完單字及文法 → 指定作業，演練該課文法及句型結構。
  4. 每上完一課 → 學習講義練習及測驗。
  5. 雜誌及核心單字是自學課程，每週都有測試，依排定考程準備。

你可以自己做的事

  • 小考前自己先默寫一次，不要等到補考。
  • 當天的文法作業當天寫，趁記憶還熱。
  • 每天讀一點雜誌，單字量是這樣累積的。
寫作弱不是你的問題，是進度的問題。
聽、說本來就比讀、寫容易學。寫作弱，通常是文法與句型結構還沒建構完成——那正是國中英文課要幫你補起來的。小學沒學好，國中一樣能學好。

ESL

敢開口，把英文用出來

ESL 的目標是讓你習慣使用生活英語、大膽開口，最後能獨立自主地用英語完成表演及報告。

課程長怎樣

  • Smart Choice：紙本＋線上系統，課本有級數，每學期隨能力提升更換。
  • 適性教學：老師依你的進度與課堂表現搭配教材與多元媒體。
  • 國際交流／期末成發：每學期有姊妹校交流，期末固定舉辦成果發表會，全英語完成表演及報告。

在家要完成的三件事

  1. Smart Choice 線上系統，依老師進度完成。
  2. 英文雜誌，依日程表養成每日閱讀。
  3. ESL 作業準時交。作業不算多，但考前會有複習及練習作業。

數學

理解 × 練習 × 訂正

數學不只是記住公式或解題步驟，更要理解「為什麼這樣算」。理解之後再適量練習，新知才會變成穩定的能力。

四個學習重點

  1. 先理解，再練習。順序反了，練再多也只是重複。
  2. 讀懂題目，找出關鍵。國中的文字敘述與情境變多了，要練習找出已知條件、問題重點與數量關係。
  3. 算式依序、完整寫下。方便檢查，也是在整理自己的思路，減少計算錯誤。
  4. 從錯題找出要加強的觀念。是題意、觀念、計算，還是步驟出問題？

平常怎麼做

  • 上課專心聽，不懂就主動問。
  • 習作、講義、指定練習確實完成，熟悉不同題型。
  • 錯題訂正後隔一段時間再做一次，確認是真的懂了。
訂正時問自己兩句：原本錯在哪裡？現在知道怎麼做了嗎？
還是不清楚，就去問老師。

歷史

從「記住」走向「理解」

國小社會和國中歷史最大的差別，不是內容變多，是問題換了。

國小社會這樣問國中歷史這樣問
發生了什麼？為什麼發生？
誰做了什麼？為什麼這樣做？
認識人物理解人物與時代
認識事件理解事件的原因與影響
老師引導自己逐漸能整理
找答案找線索、找證據

五個常見困難，這樣解

  1. 人物太多：不要只背名字。記　人物＋時代＋重要行動＋影響。
  2. 年代混亂：先後順序 → 時代位置 → 重要年代，照這個次序建立。
  3. 背了卻不會做題：代表還停在記憶。問：為什麼？→ 結果呢？→ 造成什麼影響？
  4. 史料題看不懂：先找　時間｜人物｜地點｜關鍵字｜題目要求。
  5. 不知道怎麼讀：別再反覆看同一頁。
閱讀→整理→解釋→練習→修正

歷史五問

  1. 何時？哪個時代？
  2. 哪裡？什麼地方？
  3. 誰？哪些人物或群體？
  4. 為什麼？背景與原因？
  5. 後來呢？結果與影響？
最後一定要問：這件事為什麼重要？
能回答這一題，你就有歷史思維了。

地理

讀圖 × 空間 × 數據 × 推理

地理不是背地名。每次上課前有約 10 題小測驗，用小量、持續的複習，換掉考前臨時抱佛腳。

四種要練起來的能力

  1. 閱讀與理解：從課本文字、題目敘述、資料中抓出重要訊息。
  2. 圖表與空間思考：讀地圖、統計圖表，把文字敘述轉成圖像，再比較、判斷、推理。
  3. 數據判讀與推理：人口密度、成長率、時差、比例尺——重點不是複雜計算，是理解數字代表的地理意義。
  4. 知識統整與連結：題目常常跨單元，所以除了準備這次範圍，也要持續整理核心概念。
地理科希望你帶走的不只是分數，而是圖像思考、空間概念、語文理解、數據判讀及統整推理。這些能力建立起來，分數自然會跟上。

老師也想提醒

國七還在適應階段，課堂專注、聆聽、主動參與都還在建立中。學會在適當的時間發言、討論，把注意力放回課程內容，是這學期的功課之一。

公民

有想法，也能說出理由

生活經驗→概念理解→情境分析→理性判斷

五個要跨過去的轉變

  1. 生活常識 → 公民概念：你知道「每個人都有自由」。公民課會再問：自由有沒有界線？為什麼社會需要為自由設定合理的界線？
  2. 記住名詞 → 分辨概念：權利／義務、權力／權利、自由／平等、法律／規則、政府／國家、公平／平等。
  3. 知道答案 → 分析情境：找出問題 → 連結概念 → 分析理由 → 做出判斷。
  4. 「我覺得」→ 說出「為什麼」：你的判斷依據是什麼？站在另一方的立場，又會怎麼看？
  5. 表達意見 → 理性討論：用理由與證據支持觀點，也願意聽不同的聲音。
分辨概念的四個動作：概念 → 特徵 → 生活案例 → 比較與判斷。只背定義是不夠的。

公民學習四步驟

  1. 理解概念｜這個概念是什麼？什麼是權利？什麼是義務？什麼是民主？
  2. 連結生活｜生活中哪裡看得到？「公平」跟校園生活有什麼關係？
  3. 分析問題｜誰受到影響？不同的人有什麼立場？可能有哪些衝突？
  4. 提出判斷｜我的看法是什麼？為什麼？
我的主張　＋　理由　＋　證據／例子

生物

記憶 → 理解 → 應用

生物不是「不用背」，而是要從記得進一步做到理解，最後能夠應用。記憶是起點，不是終點。

三個學習重點

  1. 建立扎實的基礎知識：名詞、構造、功能要熟。基本知識累積夠了，才有辦法比較、統整與推理。
  2. 善用圖表理解與統整：不只是把文字背起來，還要看懂圖、讀懂表格、說明構造與功能之間的關係。
  3. 透過題目練習應用：「記得」不一定代表「會用」。

課堂上會走的路

認識基本知識→看懂圖表與現象→理解概念關係→運用知識解決問題

這條路也會是之後學理化與其他自然科學的基礎。

遇到錯題，先別急著看答案。先想一句：我原本哪個觀念沒有弄清楚？
訂正加上重新理解，錯題才會變成學習。
